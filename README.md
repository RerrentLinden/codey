# Codey

Codey 是 Codex 桌面客户端的增强启动器。打开 Codey 后，它会自动拉起 Codex，并在 Codex 页面内提供统一的 Codey 控制台，用来管理线路、模型、会话、通知、插件、更新和运行策略。

## 功能描述

- 自动启动 Codex，并在 Codex 顶部显示 Codey 设置入口。
- 在 Codey 控制台查看 Codex 运行状态，并一键重启由 Codey 启动的 Codex。
- 支持官方登录线路和第三方线路，自动读取当前线路配置；未安装 CC Switch 时也兼容手工配置的 Codex 中转线路。
- 使用官方账号线路时，可选择在 Codex 顶部操作区显示 5 小时和 7 天额度的剩余比例与刷新时间。
- 兼容 CC Switch 保留官方账号登录；账号仍可显示在 Codex 中，第三方请求继续使用当前中转线路。
- 开启 CC Switch 路由后，Codey 会保留其代理线路；在 CC Switch 中热切换线路时，不会再被 Codey 的设置覆盖，Codey 增强也会自动补回。
- 支持同步当前线路的可用模型，并设置默认模型；同步失败时仍可手动确认 7 个官方模型的支持情况。
- 支持输入并保存其他模型，让第三方线路只展示实际可用的模型；官方清单内的模型需直接勾选，不能重复输入。
- 保存模型支持范围或默认模型后，会立即刷新正在运行的 Codex 模型选择器；若即时刷新失败，界面会提示重启后生效。
- 提供应用更新检查、下载和安装入口。
- 在 Codex 侧边栏显示更友好的会话时间。
- 支持导出单条会话，便于备份或迁移。
- 支持把导出的会话导入到本地项目中。
- 支持删除会话中的指定对话轮次。
- 支持恢复最近的会话备份。
- 自动修复会话恢复所需的信息，让历史会话更稳定地回到原项目。
- 修复和增强 Codex 插件市场，让官方插件和本地插件更容易发现与管理。
- 支持一键检查插件市场状态并尝试修复缺失项。
- 支持保存个性化页面增强设置。
- 支持屏蔽部分干扰性提示，让 Codex 页面更清爽。
- 提供 Codex 慢启动保护，减少卡在启动页的情况。
- 提供 Windows 启动体验优化，适合从安装包、快捷方式或终端启动。
- Windows 首次启动 Codex 失败时会显示系统错误提示并退出 Codey，处理问题后可以直接重新启动。
- Windows 未能自动找到 Codex 时，可选择并保存任意磁盘上的安装目录。
- 支持按需精简宠物功能，关闭后可恢复完整宠物体验。
- 支持按需精简语音功能，关闭后可恢复完整语音体验。
- 支持调整 Windows 上的渲染启动策略，用于排查或缓解显示异常。
- 支持上下文工具增强，改善长任务中的文件读取、搜索和替换体验；已经配置自己的 FastCtx 时会优先沿用，避免重复启用内置版本。
- 支持子代理协作优化，让适配线路上的多代理探索更稳定。
- 支持跟随官方试验性功能配置，也可以固定使用用户自己的开关选择。
- 提供精简的诊断日志统计，显示日志总量、磁盘占用和内容字节估算。
- 支持清理诊断日志，帮助控制磁盘占用。
- 支持日志写入保护，减少持续诊断日志对本地磁盘的影响。
- 支持按需添加多个飞书机器人（包括企业内网部署）或 Telegram 通知渠道，并在任务完成、失败或等待介入时同时发送提醒。
- 支持单独启停、删除和测试每个通知渠道，便于确认各渠道配置是否可用。

## 使用方式

打开 Codey 后，它会自动启动 Codex。进入 Codex 后，点击顶部的 “Codey” 按钮即可打开控制台。模型变更通常会立即更新；其他需要重启才会生效的开关或线路变更，请按界面提示保存并重启 Codex。

## 注意事项

- Codey 面向 Codex 桌面客户端，不覆盖命令行版本。
- 第三方线路是否可用取决于对应服务本身的能力与账号配置。
- 保留官方账号登录只保留 Codex 的账号状态，不会把已选择的第三方线路切回官方接口。
- 删除、导入和恢复类会话操作会尽量保留备份，但仍建议谨慎使用。
- Windows 和 macOS 上的部分运行策略需要先完全退出已有 Codex，再由 Codey 重新启动后生效。
- 部分增强能力依赖当前 Codex 版本和当前线路支持情况，遇到不兼容时请以 Codey 控制台提示为准。
